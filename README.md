# 삼목기업 AI 훈련로드맵 · 기업소개 홈페이지 초안

삼목기업의 2026년 8월 28일(금) 예정 `AI 훈련로드맵 2차 컨설팅`과,
조선·해양 협력사 소개형 홈페이지 검토를 위해 정리한 저장소입니다.

이 저장소는 지난 `snd` 저장소처럼, 단순 파일 보관이 아니라 아래 흐름이 한눈에 보이도록 구성했습니다.

- 2차 컨설팅에서 바로 설명할 수 있는 소개형 허브 페이지
- 한화오션 협력사 맥락을 참고한 삼목기업 기업소개 홈페이지 초안
- 선박의장 안전활동지수 Dashboard 시안
- 컨설팅 진행용 구성요약, 발표 멘트, 회의록 초안
- 후속 발표자료 업로드를 위한 정리된 폴더 구조

## 이번 저장소의 목적

- 2차 컨설팅에서 `AI 훈련로드맵`을 설명할 때 논의 축을 명확히 정리
- 삼목기업을 조선·해양 협력사 관점에서 소개할 수 있는 홈페이지 초안 마련
- 선박의장 현장 특성에 맞는 `안전활동지수 Dashboard` 시안을 제시
- 경영진, 센터팀장, 실무자가 같은 자료를 보고 다른 질문을 할 수 있게 구조화
